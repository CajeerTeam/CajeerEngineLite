# Совместимость ядра с CajeerEngine 2.1.0

CajeerEngine Lite 1.0.3 использует **собственное** минимальное приложение и сохраняет JSON-хранилище схемы `3`. Это **не** установка полной CMS CajeerEngine 2.1.0.

Из переданного архива CajeerEngine 2.1.0 синхронизированы оригинальные классы:

- `core/Template/CajeerTemplateEngine.php` и `TemplateExpressionEvaluator.php` — актуальные исходники 2.1.0.
- `core/Template/TemplateCompiler.php`, `TemplateSandbox.php`, `core/Public/PublicPath.php` — уже совпадали с кодом 2.1.0, менять не требовалось.
- `core/Update/OperationFiles.php` — актуальные исходники 2.1.0, включая проверку всех компонентов пути при создании каталогов.
- `core/Update/OperationLock.php` — оригинальные примитивы блокировок 2.1.0; Lite использует `openLockFile` для синхронизации изменений сайта.

`core/Lite.php` интегрирован с `OperationFiles` и `OperationLock`: запрет подменённого JSON/lock-файла и symlink-каталогов, атомарная запись с синхронизацией каталога, защита от параллельных изменений через `flock`. Не требуется Composer, SQL или Redis. Существующий `storage/site.json` (schema 1) автоматически либо командой CLI мигрирует на schema 3 с предварительной резервной копией.

## Что не включено

Подсистемы полной CMS 2.1.0 (API, БД, Nuxt Admin, работники очередей, обновление с Ed25519-подписью, комплексное восстановление полной CMS, Update Center и системный оператор) **не** включены: они зависят от полного ядра, Composer и инфраструктуры CMS. Перенос их в Lite без полного редизайна изменил бы продукт и не представлял бы собой безопасное обновление. Lite по-прежнему **не предоставляет автоматического обновления**. Версия приложения Lite — `1.0.3`; `ENGINE_BASE_VERSION = 2.1.0` обозначает уровень синхронизированных общих компонентов.

## Проверка

```
php tests/smoke.php
php tests/core_210.php
php tests/core_102.php
php tests/core_103.php
bash tests/http.sh
php bin/cajeer doctor
```

Последняя команда выполняется после установки. Использовать PHP 8.4.1+ и размещать каталог проекта за пределами DocumentRoot (`public/`).

## Версия 1.0.2

`SiteRepository` управляет сериализованными изменениями и атомарным коммитом JSON. `SiteState` валидирует и мигрирует schema 1 → 2. `BackupService` создаёт, проверяет и восстанавливает приватные снимки с SHA-256; доступен из CLI. `ModuleConfig` управляет реальными веб-функциями navigation, robots, sitemap, включая веб-панель. Это новые функции Lite, а не перенос полной CMS.

## Версия 1.0.3

`ConsentConfig` задаёт редактируемые и строго проверяемые параметры политики. `ConsentCookie` верифицирует сохранённый выбор посетителя с учётом срока и ревизии. `public/assets/consent.js` обеспечивает реальное управление выбором и отзывом разрешений, в том числе доступ через постоянную кнопку в футере. Публичная CSP разрешает собственные скрипты; административная панель не разрешает JavaScript. `SiteState` переводит schema 1/2 → 3 под блокировкой с неизменяемой проверяемой резервной копией старого состояния.
